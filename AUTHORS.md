# Authors and Contributors

FTC Dev Tools was founded and initially developed by **The Allsparks**, a FIRST Tech Challenge team based in Las Vegas, Nevada.

The project is maintained for The Allsparks and the broader FTC community.

## Founding organization

- The Allsparks

## Contributors

Individual contributors are recognized through:

- the Git history
- the GitHub contributors list
- pull requests
- release notes
- this file where appropriate

Contributors do not need to be members of The Allsparks.

## Attribution policy

Substantial contributors may be added to this file with their consent.

Do not add personal information beyond what a contributor has already chosen to make public through GitHub or explicitly approves for inclusion.

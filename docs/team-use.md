# How The Allsparks Use FTC Dev Tools

FTC Dev Tools is developed from real needs encountered by The Allsparks, but it is intentionally separated from the team’s robot code and private operations.

## Public repository

This repository contains reusable tools such as:

- environment diagnostics
- build and deployment workflows
- device discovery
- Logcat tools
- SDK update helpers
- FTC project scaffolding
- robot configuration helpers
- hardware-map generation
- editor integrations
- documentation and test infrastructure

## Separate team repositories

The Allsparks keep the following outside FTC Dev Tools:

- robot source code
- competition strategy
- unreleased mechanisms
- team credentials
- device serial preferences
- Wi-Fi credentials
- private sponsor information
- student information
- internal schedules and operations

## From team need to community feature

A feature discovered through Allsparks team use should enter FTC Dev Tools only after it is:

1. generalized beyond one robot or team
2. reviewed for safety
3. documented
4. tested
5. configurable where teams differ
6. free of private team data
7. useful to the broader FTC community

## Experimental team use

The Allsparks may test unreleased features before public release.

Experimental use must not be presented as community-wide hardware validation until it has been tested and documented appropriately.
